### 12. FAQ Section

**Headline:**
"Frequently Asked Questions"

**Q: Is FlowBoard really free?**
A: Yes! Completely free. No hidden costs, no premium tiers, no per-user pricing. We believe good tools should be accessible to everyone.

**Q: How do you make money then?**
A: FlowBoard is an open-source passion project. We're not a company trying to extract value from you. It's free because we believe in building good software, not because we're trying to upsell you later.

**Q: Where is my data stored?**
A: Locally in your browser's storage. It never leaves your device. No cloud sync means no servers, no breaches, no data mining.

**Q: What if I clear my browser data?**
A: Your FlowBoard data will be deleted too. We recommend exporting your board periodically (feature coming soon) or using it on a device you don't regularly clear.

**Q: Can I use it on multiple devices?**
A: Since data is local-only, each device has its own board. We're exploring privacy-friendly sync options for the future.

**Q: Can teams use FlowBoard?**
A: Absolutely! While there's no built-in collaboration features (to maintain privacy), teams can use it for individual task management or share screens during standups.

**Q: Is FlowBoard better than [Competitor]?**
A: Different tools for different needs. FlowBoard is best if you value: privacy, simplicity, beautiful design, and free access. If you need complex workflows, integrations, or team collaboration features, other tools might fit better.

**Q: What tech stack is FlowBoard built with?**
A: Next.js 16, React 19, TypeScript, Tailwind CSS, and dnd-kit for drag-and-drop. Modern, performant, and delightful to develop with.

**Q: Can I contribute to FlowBoard?**
A: Yes! We welcome contributions. Check out our GitHub repo for issues, feature requests, and contribution guidelines.

**Q: Will FlowBoard always be free?**
A: Yes. It's open source under MIT license. Even if we stopped maintaining it, the community could continue.

## Design Guidelines

### Color Palette

**Primary Colors:**
- Purple: #9333ea (primary actions, branding)
- Blue: #3b82f6 (accents, links)
- Cyan: #06b6d4 (highlights)

**Gradients:**
- Hero: `from-purple-50 via-white to-blue-50`
- Sections: `from-purple-100 to-blue-100`
- CTA Buttons: `from-purple-600 to-purple-700`

**Neutral Colors:**
- Text: #111827 (gray-900)
- Secondary text: #6b7280 (gray-500)
- Borders: #e5e7eb (gray-200)
- Background: #ffffff

### Typography

**Headings:**
- Font: Inter, System-UI, sans-serif
- H1: 3.5rem (56px), bold, tight leading
- H2: 2.5rem (40px), bold
- H3: 1.875rem (30px), semibold
- H4: 1.5rem (24px), semibold

**Body:**
- Font: Inter, System-ui, sans-serif
- Base: 1rem (16px), regular
- Large: 1.125rem (18px)
- Small: 0.875rem (14px)

### Spacing

- Section padding: 5rem (80px) vertical
- Container max-width: 1280px
- Grid gaps: 2rem (32px)
- Element spacing: 1rem (16px) default

### Components

**Buttons:**
- Primary: Purple gradient, white text, rounded-lg, shadow-lg
- Secondary: White bg, purple border, purple text
- Sizes: Large (px-8 py-4), Medium (px-6 py-3)

**Cards:**
- White background
- Rounded-xl corners
- Subtle shadow (shadow-sm hover:shadow-lg)
- Border: 1px solid gray-200
- Padding: 2rem

**Icons:**
- Size: 24px for feature icons
- Color: Match purple/blue theme
- Style: Outlined or emoji for personality

### Animations

**Scroll Animations:**
- Fade up on scroll
- Stagger children for lists
- Smooth, subtle (300-500ms)

**Interactive:**
- Hover states on all clickable elements
- Scale transforms (1.02-1.05)
- Color transitions
- Shadow depth changes

**Micro-interactions:**
- Button press feedback
- Card hover lift
- Icon bounces on emphasis

### Responsive Design

**Breakpoints:**
- Mobile: < 640px
- Tablet: 640px - 1024px
- Desktop: > 1024px

**Mobile Adjustments:**
- Stack columns vertically
- Reduce heading sizes by 25%
- Simplify animations
- Touch-friendly button sizes (min 44px)

## Conversion Optimization Tips

1. **Above the Fold:**
   - Clear value proposition
   - Immediate CTA
   - Visual proof (demo)

2. **Social Proof:**
   - Early placement
   - Real names and roles
   - Specific results

3. **Reduce Friction:**
   - No signup required emphasized
   - One-click to app
   - Show, don't tell (demos)

4. **Trust Signals:**
   - Open source badge
   - GitHub stars
   - Privacy commitments
   - Real testimonials

5. **Multiple CTAs:**
   - Hero section
   - After each major section
   - Final push at bottom

6. **Objection Handling:**
   - FAQ section
   - Privacy deep-dive
   - Comparison table
   - Testimonials addressing concerns
